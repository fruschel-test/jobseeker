# Talent Bridge AU/NZ

Painel estático de pesquisas de vagas com foco em visa sponsorship e relocation para Austrália e Nova Zelândia.

## Publicar no GitHub Pages

1. Crie um repositório público chamado `talent-bridge-au-nz`.
2. Envie `index.html` para a raiz do repositório.
3. Em **Settings → Pages**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/(root)` e salve.
5. Aguarde a publicação. O endereço será parecido com `https://SEU-USUARIO.github.io/talent-bridge-au-nz/`.

O site é estático: não usa banco de dados, backend nem segredos. Os links abrem pesquisas nos sites externos; o GitHub Pages não executa consultas próprias nem atualizações automáticas.
